# Données du jeu — DBZ: Attack of the Saiyans

Règle : **rien sans source**. Chaque ligne cite sa source (voir la liste en bas). Pas de source = pas de ligne.

## Format
- Nom FR = ce qui s'affiche à l'écran (version EU, jeu en français).
- Nom EN = nom des guides anglais. C'est lui qu'on utilise dans le world Archipelago.
- Source = code de la liste « Sources » + précision (page, section, minute de vidéo…).
- Statut : ✅ vu en jeu · 📖 trouvé dans un guide seulement · 🔍 extrait de la ROM.
